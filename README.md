# 罗辑思维框架 Skill

从刘慈欣《黑暗森林》《死神永生》中的罗辑提炼条件推演、异常反推、信息策略、可信承诺与长期责任。包含剧透。默认是思维顾问，非原作者或角色官方作品。

## 使用

将整个 `luo-ji-perspective` 文件夹放入 Codex 的 skills 目录。已在本机目录安装；如当前会话的技能列表未刷新，可新开会话。

调用示例：
- 用罗辑视角分析这个项目承诺是否可信。
- 用罗辑的思维框架检查我的假设，给出反证和下一步。
- 对比罗辑、章北海和维德的决策方式。

`SKILL.md` 是入口，`references/research` 保存依据、局限与验证记录。后期情节主要采用标明等级的二手研究，不宣称完整原著核查。现实迁移不预设人人敌对。
